# DropDeck

DropDeck is an intelligent, automated inventory and financial tracking dashboard designed specifically for high-frequency collectors and resellers. It eliminates the need for tedious manual spreadsheet entries by automating the entire lifecycle of an order—from purchase confirmation to final sale.

## 🚀 Key Features

* **Automated Email Parsing:** Instantly reads incoming order confirmation emails to automatically capture purchase location, item names, quantities, and cost basis.
* **Smart Inventory Triage:** Automatically routes newly parsed orders into designated "Resale" or "Personal Collection" status buckets.
* **EBay API Integration:** Seamlessly syncs with your eBay store to detect completed sales, instantly matching transactions to calculate exact realized profits and margins.
* **Actionable Insights Dashboard:** Real-time visibility into active orders, pending tracking numbers, win rates for raffle drops, and overall financial performance.
